# Changelog

## [0.1.0] — initial release

Forked from [tmchow/illo-skill](https://github.com/tmchow/illo-skill) v0.35.0
(MIT © Trevin Chow) with a new identity:

- New name: **lukis** (`/lukis`), config at `~/.config/lukis/`.
- New default mascot: **Ciko**, a deadpan house gecko (cicak) with an
  accent-tipped curled tail; aliases `cicak`, `gecko`, `lizard`.
- New default look: **sablon** — hand-pulled screenprint (flat spot-color
  inks, no halftone, stencil-wobble edges, bare-paper seams between ink
  layers). riso remains a bundled look.
- New house palette: **pasar** (warm cream, warm near-black, chili red,
  leaf teal); `ink-punch` remains a preset.
- Community character catalog still served from the upstream
  `tmchow/illo-characters` repo (override with `packsRepo` in config).
