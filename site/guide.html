Say "lukis" and give the skill an idea, a post, or an article URL. One image explains one idea: a key judgment, a flow, a before/after, a trap, a loop. The default mascot is Ciko, a deadpan house gecko, in sablon — hand-pulled screenprint on the pasar palette.

The explainer register: labeled stages, one connected system, hand-built.

Pick a register

  • Editorial scene (default): one caught moment, the mascot performing the idea. Best for heroes and single illustrations.
  • Mini-comic: 2–4 panels in one image when the idea is a story beat (fail→fix, before→after). Not for named pipelines.
  • Explainer diagram: labeled stages, flow, fan-out, timeline, loop, stack, or system slice when the structure is the point.
  • Character cutout: the mascot alone on transparency for overlay. Pose only, no scene, no text.
  • Surprise / random: no thesis yet. The skill invents three candidates, you pick (or --autopick), it renders one plus a caption line.

First commands

/lukis you are the bottleneck
/lukis https://yourblog.com/shipping-discipline hero + 3 images
/lukis surprise me
/lukis surprise me --autopick using ciko
/lukis how a book gets published explainer diagram
/lukis ciko cutout waving
/lukis X Article banner for this post

Image backends

The engine renders through one of four backends, resolved by host capability or pinned with --backend:

  • Codex: signed-in Codex CLI, built-in image generation. No API key. Default.
  • Grok CLI: signed-in Grok CLI. No API key. No transparent cutouts.
  • Grok Bot: Grok Bot's built-in image tool. No cutouts.
  • OpenRouter: key stored by lukis.py init in ~/.config/lukis/config.yaml. Model-selectable. Paid fallback only with --allow-paid-fallback, never automatic.

Characters and looks

Character packs couple one mascot with one print look — never freely swappable. Eighteen bundled looks: sablon, riso, blueprint, woodcut, pixel, clay, manila, chalk, phosphor, enamel, gouache, felt, diorama, sketchbook, bricks, fizz, bloom, snes. Calibrated examples for sablon, riso, woodcut, chalk, and enamel ship in the repo. Say /lukis build a character to design your own.

Output guidance

  • One strong visual metaphor beats many props.
  • Editorial scenes by default; mini-comic for story beats; explainer for traceable structure; cutout for overlay only.
  • For an X Article banner / hero, use 1536 × 640.
